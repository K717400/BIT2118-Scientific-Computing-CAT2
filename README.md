# BIT 2118 Scientific Computing CAT 2

## Setup
1. Install Python 3.
2. Open this folder in VS Code.
3. In the terminal run: `python -m pip install -r requirements.txt`
4. Run: `python main.py`

The program prints calculations and creates charts/cleaned data in `outputs/`.

**Important:** `sales.csv` is illustrative sample data because no lecturer-provided CSV was included with the CAT PDF. Replace it with the official dataset if one was supplied separately.
